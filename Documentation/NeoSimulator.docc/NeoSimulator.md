# NeoSimulator

Choose a CoreSimulator display host for Xcode 27+.

@Metadata {

## Overview

Display and control devices using Xcode's private simulator frameworks, while
Xcode handles Build & Run. Choose NeoSimulator or Device Hub in Settings.
